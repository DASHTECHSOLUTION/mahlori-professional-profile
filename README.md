# Mahlori Makwakwa | Professional Portfolio

A modern personal portfolio website built to showcase professional background, projects, skills, education, certifications, and contact details.

## Project Overview
This portfolio is designed for job and internship applications with a polished, responsive single-page layout and professional content structure.

## Features
- Responsive landing page and section-based layout
- About Me, Skills, Projects, Education, Certifications, Experience, and Contact sections
- Downloadable CV file
- Clean modern UI with accessible design
- GitHub Pages ready static site

## Run locally
Open `index.html` directly in a browser, or serve the project locally using a static server.

Example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to GitHub Pages
1. Push these files to the repository's `main` branch.
2. In GitHub, open the repository.
3. Go to Settings > Pages.
4. Select the `main` branch and the root folder (`/`).
5. Save.

Your portfolio will be available at the GitHub Pages URL for the repository.
